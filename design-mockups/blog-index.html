Blog 頁 — 5 種版本

EDITORIAL · 主題色 · 偏閱讀導向（與 Projects 卡片風格刻意不同）
V1

Reading List

單欄閱讀清單：日期·分鐘、大標、摘要、tags、細線分隔。最像個人誌、最好讀。
V2

Date Rail

左側日期時間軸（圓點 rail）＋右側標題摘要。有編年、時間軸感。
V3

Featured Lead

最新文章大版置頂，其餘為精簡兩行列。突出最新、其餘掃讀。
V4

Numbered Notes

編號筆記本：大編號＋標題＋日期＋摘要。標題用斜體 Notes，最有個人風格。
V5

Tag Index

頂部 tag 篩選列＋索引式表格（標題／Tags／日期）。最像可檢索的文章庫。
這些是 Blog 列表頁的方向探索；內文為示意（取材自你真實的技術主題，正式內容會由後端 /posts 提供）。選定後我會用 Next.js 實作 /blog 與 /blog/[slug]，並開啟 header 的 Blog 分頁。皆遵守 claude-design-x（無激進漸層 / 無 emoji / 無圓角左邊框卡片 / 無假 SVG 圖；偏排版與留白）。
